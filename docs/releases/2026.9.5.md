# v2026.9.5

You can now install or reload supported plugins without restarting the Gateway. This release also adds guided setup for teams of specialist agents and brings GPT Live to meetings and phone calls.

**Release scale:** 1,497 pull requests, 13 direct commits, and 213 contributors.

## Installation and Onboarding

Setup gives you more ways to shape a new agent, with clearer guidance when installation or a first connection needs attention.

<AccordionGroup>

<Accordion title="Set up a specialist team">

Start with a chief of staff, researcher, writer and reviewer, or choose a single specialist. [Guided setup](/start/wizard) can create the four-agent team, and **New agent** in the web UI offers the same roles through a proposal you approve before anything is created. Setup remembers your chosen coordinator if you need to resume. Choosing **Skip** creates the team offline, with AI access still to configure.

If creation stops partway through, check `openclaw agents list` and repair the incomplete team before retrying. If all four members already exist, finish with `openclaw onboard --workspace <workspace>` without `--team`.

<summary>Sources and complete change list</summary>

**Improvements**

- Offer specialist roles and approved team creation through New agent [#141453](https://github.com/openclaw/openclaw/pull/141453).
- Create role-based agents and coordinator-led teams with separate workspaces [#145712](https://github.com/openclaw/openclaw/pull/145712).

**Bug fixes**

<Accordion title="Choose an avatar for a new agent">

Once you agree on your new agent's name and personality, setup can offer four matching portraits to choose from. This needs an available image provider and saves your choice after you select it. You can keep the emoji by skipping, and setup can continue with it if generation or saving fails.

<Accordion title="Start with fewer setup decisions">

Fresh OpenAI and ChatGPT/Codex setups default to Astra when you have not chosen a primary model. Existing model choices stay in place. If your account does not offer Astra, choose an available model during [OpenAI setup](/providers/openai/setup). Verified official plugins also skip the redundant capability approval on the way to authentication, while third-party and unverifiable plugins still need the applicable [consent](/cli/plugins/install).

<Accordion title="Recover command-line installation">

The installer reuses compatible Node and nvm installations without unnecessary system replacement or shell-profile changes. If it needs to install Node through nvm, it asks first and explains any default-alias changes. Declining or running unattended leaves you with preparation commands.

Mac app CLI setup can now recover from temporary-directory permission errors without an administrator password.
